===== help: root =====
media-aware regression diff


mediadiff [OPTIONS] [baseline] [candidate] [SUBCOMMAND]


POSITIONALS:
  baseline TEXT               Baseline artifact or *.snap.json (implicit compare)
  candidate TEXT              Candidate artifact or *.snap.json (implicit compare)

OPTIONS:
  -h,     --help              Print this help message and exit
          --version           Display program version information and exit

SUBCOMMANDS:
  compare                     Compare two artifacts (or snapshots)
  snapshot                    Write a *.snap.json fingerprint (or re-materialize an existing
                              one)
  dir                         Compare two directories of media artifacts (corpus diff,
                              DIR-01..05)
  inspect                     Render every implemented check family for a single *.snap.json
                              (UC8)
  list-checks                 List registered checks, or the resolved effective policy
  explain                     Print compiled-in documentation for a check (ENG-13, DOC-02)
===== help: compare =====
Compare two artifacts (or snapshots)


mediadiff compare [OPTIONS] baseline candidate


POSITIONALS:
  baseline TEXT REQUIRED      Baseline artifact or *.snap.json
  candidate TEXT REQUIRED     Candidate artifact or *.snap.json

OPTIONS:
  -h,     --help              Print this help message and exit
          --strict            A worst-warn finding also fails the run (exit 2)
  -v,     --verbose           Under --json, also render each finding's severity_chain
  -q,     --quiet             Suppress the human-readable TTY report on success
          --json TEXT         Render the report as JSON: bare '--json' writes stdout,
                              '--json=PATH' writes PATH
          --report TEXT ...   Write a file-bound report: '--report md=PATH' or '--report
                              junit=PATH' (repeatable)
          --profile TEXT      Select a shipped profile (default: sw-encoder)
          --config TEXT       Path to mediadiff.toml (default: ./mediadiff.toml if present)
          --set TEXT ...      Override a check's severity: <glob>=<ignore|info|warn|fail>
          --tol TEXT ...      Override a check's tolerance: <glob>=<tolerance text>
          --no-color          Disable ANSI colour output regardless of environment
          --ascii             Use ASCII status words (OK/WARN/FAIL/INFO) instead of Unicode
                              glyphs

Note: a bare positional named exactly 'compare' is always parsed as this
subcommand. To compare a file literally named 'compare', path-qualify it (e.g.
'./compare') or use 'mediadiff compare ./compare <candidate>'.

===== help: dir =====
Compare two directories of media artifacts (corpus diff, DIR-01..05)


mediadiff dir [OPTIONS] baseline_dir candidate_dir


POSITIONALS:
  baseline_dir TEXT REQUIRED  Baseline directory
  candidate_dir TEXT REQUIRED Candidate directory

OPTIONS:
  -h,     --help              Print this help message and exit
          --threads INT       Bounded worker-pool size (default: hardware concurrency)
          --content           Enable the decode-pass content checks (opt-in for dir mode)
          --no-content        Explicitly disable the decode-pass content checks (dir mode's own
                              default)
          --profile TEXT      Select a shipped profile (default: sw-encoder)
          --config TEXT       Path to mediadiff.toml (default: ./mediadiff.toml if present)
          --set TEXT ...      Override a check's severity: <glob>=<ignore|info|warn|fail>
          --tol TEXT ...      Override a check's tolerance: <glob>=<tolerance text>
          --json TEXT         Render the report as JSON: bare '--json' writes stdout,
                              '--json=PATH' writes PATH
          --report TEXT ...   Write a file-bound report: '--report md=PATH' or '--report
                              junit=PATH' (repeatable)
          --no-color          Disable ANSI colour output regardless of environment
          --ascii             Use ASCII status words (OK/WARN/FAIL/INFO) instead of Unicode
                              glyphs
          --strict            A worst-warn finding also fails the run (exit 2)
  -q,     --quiet             Suppress non-error output
  -v,     --verbose           Also render each finding's severity_chain / resolution chain

Note: by default `dir` runs the header-plus-packet pass set only (no decode).
--content additionally requests the decode-pass content checks, which trades
corpus speed for coverage -- expect a `dir` run to take substantially longer per
file with --content set.
