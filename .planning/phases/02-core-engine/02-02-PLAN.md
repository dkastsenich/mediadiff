  <action>
Implement `src/core/glob.{h,cpp}` with two entry points:
`bool glob_matches(std::string_view pattern, std::string_view check_id)` and
`std::vector<std::uint32_t> glob_select(std::string_view pattern, const CheckRegistry&)`.

The algorithm splits both pattern and ID on `.` into segments and compares
segment-wise. A literal segment must be byte-equal. A `*` segment matches exactly
one whole segment and never part of one. A `**` segment is legal only as the
final pattern segment and matches one or more remaining segments — it does not
match zero, so `container.ts.**` does not match `container.ts`. A pattern with an
empty string, or with an empty segment produced by a leading, trailing or
doubled `.`, matches nothing. A `**` in any position other than last is a
malformed pattern: return an empty match set and expose the reason through a
`mediadiff::expected` overload the config layer can turn into a `usage` `Error`
in plan 02-06. Do not include `<regex>` and do not construct any regular
expression — ENG-02 forbids it, which also removes catastrophic-backtracking as
a class from this input surface.

`glob_select` walks the registry in declaration order and returns matching
indices in that order, so two invocations of the same pattern produce the same
sequence and downstream policy resolution is deterministic.

Write `tests/unit/test_glob.cpp` under the tag `[glob]`, covering at minimum:
exact match; `*` matching one segment; `*` refusing a partial segment
(`container.ts*` must not match `container.tsx.foo`); `*` refusing to match
across a `.`; `**` matching two trailing segments; `**` refusing to match zero
trailing segments; the empty pattern matching nothing; a doubled-dot pattern
matching nothing; a `**` in non-final position being rejected; and
`glob_select` returning indices in registry declaration order. Add the file to
`add_executable(mediadiff_unit_tests ...)` and add `src/core/glob.cpp` to
`add_library(libmediadiff STATIC ...)`.
  </action>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `--set` / `mediadiff.toml` glob string -> `src/core/glob.cpp` | Untrusted pattern text crosses into policy resolution |
| `checks.def` + `docs/checks/*.md` -> generated C++ | Repository content becomes compiled source at build time |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-2-02 | Tampering | `src/core/glob.cpp` | medium | mitigate | The matcher is a segment-wise split-and-compare with no regular expression anywhere, which removes catastrophic backtracking as a class from this input surface (ENG-02). Malformed patterns return an empty match set plus a reportable reason rather than undefined behaviour. |
| T-2-08 | Tampering | `tools/gen_registry.py` | high | mitigate | Doc bodies become raw string literals in generated C++. The generator chooses a raw-literal delimiter that the doc content cannot terminate, and rejects any doc whose content would still close the literal, so repository Markdown cannot inject code into the compiled binary. |
| T-2-09 | Spoofing | `docs/checks/` | medium | mitigate | An orphan `docs/checks/*.md` whose stem is not a registered ID fails the build, so a renamed check cannot silently keep serving the old document as if it were current. |
| T-2-10 | Denial of Service | `tools/gen_registry.py` | low | accept | The generator reads a fixed, in-repository file set at build time; there is no untrusted-caller amplification path. |
</threat_model>
