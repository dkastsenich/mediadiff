<objective>
Close CR-05 and its secondary finding, and correct WR-09's stale comment (06-REVIEW.md, VERIFICATION.md gap 3).

CR-05. The D-12 fallback probe keeps its wall-clock interrupt armed through its reads. On a loaded runner an interrupted open or read turns into `unknown`. "LC (sbr: implicit)" on one run then becomes "LC (sbr: unknown)" on the next, and a file compared against an identical copy fails. That violates checks.def's own "a check's value must never depend on which passes ran" and the project's determinism constraint.

This plan takes the review's second option:
- the probe's reads become deterministic, bounded by the existing 64-packet scan limit, the same stance PacketScan takes after open;
- an open failure, a timeout included, becomes a hard Error rather than a value.

"Which passes ran": the probe runs inside DemuxSession::open in every mode (snapshot, compare --content, compare --no-content, dir), so once timing is out the value depends only on the file's bytes. WR-08's analyzer-set dependence is a different mechanism; it is deferred (see 06-14), and these tests would not catch it.

CR-05 secondary. The `profile_is_he_aac` header branch returns `implicit_decoded` with no rate evidence, and the stream_info comment claims the rate is doubled "by construction". This plan carries decode-observed rate evidence for every implicit_decoded resolution and asserts it against the decode sweep.

WR-09 (comment only). Correct stream_params.cpp's stale claim. Do not implement WR-09's Fix. 06-15 records how far its declared/decoded split subsumes WR-09's naming concern.

Purpose: audio.profile is a pure function of the file's bytes, and its rate evidence is always the decoder's.
Output: a deterministic probe with Error propagation, SbrResolution, tests, the corrected comment, docs, a timeline ratchet measurement and a corpus differential.
</objective>

<flagged_assumptions>
**A1: classification of probe failures.**
- Error: container open or find_stream_info failure, including a timeout; allocation failure; the target index absent on the second open. These depend on the environment or on the file changing between opens.
- ok(nullopt): no decoder, parameter-copy or avcodec_open2 failure, no target packet within 64 packets, a send failure, or no frame. These are deterministic for the same bytes and the same build.
The Error set matches what DemuxSession::open already treats as fatal for its own open.

**A2: disarming the probe's reads trades the wall-clock arm (06-04's T-06-13 mitigation) for determinism.** The read stage stays bounded by the 64-packet scan and one decoder packet. That is the same stance the primary session takes for PacketScan after its open (the 03-03 disarm).

**A3: the zero-budget test relies on avformat_open_input consulting the interrupt callback.** test_demux_session.cpp's "a 0ms wall-clock budget fails immediately" already proves that for the primary open with the same open_context, so the probe inherits it.
</flagged_assumptions>
