<objective>
`audio.silence.edges` and `audio.silence.dropouts` — introduced leading or trailing silence and
interior dropouts reported as spans, detected inside the same decode sweep the hash and loudness
sinks already share.

Purpose: introduced leading silence is a sync or gapless-playback bug and an interior dropout is the
classic buffer-handling regression — both are invisible to every parameter check and to loudness,
which averages them away. This is also the third and final sink, so it is where AUDIO-10's
single-sweep guarantee becomes complete and measurable for PERF-04.
Output: the span detector in the shared sweep, two registered checks with their `--explain` docs
echoing their named thresholds, and their fixture pairs.
</objective>

check docs so a user can see it rather than infer it.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| decoded PCM → the sliding RMS window | attacker-influenced sample data drives a windowed accumulator |
| container-declared sample rate → span boundary derivation | a declared rate converts sample indices into reported times |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-30 | Denial of Service | the sliding RMS window sized from a declared sample rate | medium | mitigate | derive the window length from the DECODED frame's rate, clamp it to a sane maximum expressed as a named constant, and skip the detector with an explicit not-measured state rather than allocating from an unvalidated figure |
| T-06-31 | Denial of Service | an unbounded span list on a pathological input alternating above and below the threshold every sample | medium | mitigate | the hysteresis window and the minimum-span rule both bound the number of emittable runs; additionally cap the emitted span count with a named constant and record truncation in evidence rather than growing without bound |
| T-06-32 | Tampering | integer overflow converting a very large sample index to rational time | high | mitigate | every conversion goes through `src/core/rational.h`'s checked helpers and yields an explicit not-measured state on overflow, never a wrapped or truncated timestamp |
| T-06-SC | Tampering | npm/pip/cargo installs | high | accept | no package-manager install occurs in this plan; every dependency is already pinned in `vcpkg.json` |
</threat_model>
