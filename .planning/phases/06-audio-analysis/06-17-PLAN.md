<objective>
Close CR-04 from 06-REVIEW.md (VERIFICATION.md gap 3). The -1.0 dBTP escalation fires on a knife-edge: a 0.0002 dB change that crosses the milli-dB quantised ceiling hard-fails despite a 0.3 dB tolerance. That is the false-positive class this project treats as P0.

**Chosen fix: a rise deadband inside tol.cpp's generic escalation.** The asymmetric rule still escalates regardless of tolerance, but only when the candidate rose across the ceiling by at least 0.010 dB.

Why 0.010 dB (all sources measured or in-repo):
- It is 10x the 0.001 dB quantiser step (kLoudnessQuantiserDen = 1000), which is where the review's 0.0002 dB example straddles.
- It is 10x the 0.001 dB shift a sub-LSB PCM perturbation produced in debug session true-peak-cross-platform (`.planning/debug/resolved/true-peak-cross-platform.md`, about line 632: -18.056 -> -18.055 under pcm_s16le).
- It is 1/30 of the check's own 0.3 dB tolerance.
- It is 23x below the 0.237 dB swing a lossy AAC path amplified that same perturbation into. A crossing of that size is exactly the headroom risk the rule exists for, and it still escalates.

**Rejected shapes (from the review):**
- (1) Gate on `!within_warn`. audio.loudness.true_peak's tolerance "0.3dB" has one threshold. tol.cpp sets within_warn only when a warn threshold exists, so for this check `!within_warn` is always true and the gate would be a no-op. Read as its evident intent, `!within_fail`, it would pass every crossing inside 0.3 dB (-1.05 -> -0.95 dBTP would pass). That contradicts AUDIO-06, SC3 and the doc's "regardless of tolerance".
- (2) A third analyzer-side "at" state within ±deadband. That is an evidence contract change (a new ceiling_state value in snapshots, --json, inspect -v and goldens). Worse, it hides large crossings whose candidate lands inside the band: -1.5 -> -0.995 dBTP, a 0.505 dB rise, would never escalate.

The chosen delta deadband suppresses only pairs whose whole movement is under 0.010 dB, and it changes no evidence.

06-CONTEXT.md records no decision about the ceiling rule; it comes from doc 05 section 4 through AUDIO-06. Nothing locked is reversed.

Purpose: the asymmetric headroom rule stops crying wolf on quantiser noise and keeps catching every material crossing.
Output: the deadband constant, the gated escalation, boundary tests and docs.
</objective>
