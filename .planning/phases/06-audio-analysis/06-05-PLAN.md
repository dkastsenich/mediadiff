<objective>
The decode-determinism policy made mechanical: automatic class-1 decoder preference with a
`--hash-decoder` opt-out, the per-hashed-stream record every fingerprint carries, and the two proofs
that the class system actually works — a class-1 hash that compares equal across builds, and a
class-2 hash across differing paths that skips instead of lying.

Purpose: this is the plan that turns doc 01 §7's decode-determinism classes from shared vocabulary
into a mechanically enforced guarantee, which is the phase goal's own wording. Without the recorded
per-stream path, a class-2 hash taken on one machine and compared on another would be COMPARED rather
than skipped, and would report a fabricated fail — the exact failure mode TRUST-02 exists to prevent.
Output: `--hash-decoder`, the class table, the populated `Envelope::decode_path` array, and the
three-way class proof doc 05 §6 names in its acceptance section.
</objective>
