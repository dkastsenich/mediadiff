<objective>
`audio.priming` — the check that completes the precedence chain Phase 5 started, makes losing or
gaining priming signaling a reported regression, and carries trailing padding in its evidence for the
span fix 06-07 consumes.

Purpose: Phase 5 shipped `timeline.av_offset` with a visible `priming: unknown` gap because the audio
decode path did not exist. ROADMAP SC2 scopes closing that gap to this phase, and the resolver is the
half that has to land before the span fix can use it. 06-RESEARCH.md's highest-value finding
substantially narrows what the container-mechanism tier has to be: libavformat already folds MP4
`elst`, iTunSMPB and MKV `CodecDelay` into the two fields Phase 5's resolver already reads, so the
tier's real job is evidence transparency and two named edge cases — building it as a parallel
computation would duplicate libav and risk disagreeing with the value the same file already reports.
Output: the extended resolver, one registered check whose `unknown` is a comparable value, and the
measured answer for the multi-edit and fragmented MP4 cases.
</objective>
