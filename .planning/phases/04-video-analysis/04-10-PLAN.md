<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| attacker-controlled per-access-unit field-order values -> the tally | Every value is a file-influenced integer the analyzer counts and divides by. |
| attacker-controlled access-unit cardinality -> the proportion denominator | A zero denominator would be a division by zero; a very large one grows the tally walk. |
| a declaration that disagrees with the frames -> the compared value | Choosing the wrong one of the two silently changes what the check means. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-4-44 | Denial of Service | the proportion denominator being zero | high | mitigate | The no-observed-field-order case is handled before any division: the check emits the declared value with a no-cross-check marker, so the division never executes with a zero denominator. |
| T-4-45 | Tampering | a floating-point proportion breaking `--json` byte-identity | medium | mitigate | Proportions are exact `num`/`den` rationals computed with the checked helpers; an acceptance criterion greps the translation unit for floating-point types and a test compares two `--json` runs byte for byte. |
| T-4-46 | Denial of Service | the field-order tally over a very large access-unit array | low | accept | The access-unit array is already bounded by plan 04-01's shared byte budget and the per-stream packet ceiling; the tally is a single pass with a fixed, small number of buckets drawn from libav's own closed field-order enumeration. |
| T-4-47 | Repudiation | a declared field order presented as if it had been verified | medium | mitigate | Evidence always carries whether a per-frame cross-check was possible; the no-parser and no-known-field-order paths both set it, so a reader can tell a verified value from a reported declaration. |
| T-4-SC | Tampering | npm/pip/cargo installs | low | accept | No package is installed by this plan. |
</threat_model>
