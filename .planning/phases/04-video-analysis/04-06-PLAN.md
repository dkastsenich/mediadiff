<flagged_assumptions>
**A1 — The level-rendering table is this project's own, not libav's.** Doc 03 §2 specifies a
codec-specific human string with its own table (H.264 31 renders 3.1, HEVC 123 renders 4.1 with
main-tier flagging, AV1 8 renders 4.0). libav has no single API that produces these, so the table
is hand-written here and becomes part of the compared value — which means it is effectively as
permanent as the check id. Keep it small, cover only the codecs the v1 matrix actually contains,
and render an unrecognised level as its raw integer rather than guessing.

**A2 — Spec-less edge probe.** Two of the 17 unresolved probe items are authored into this plan's
`truths`: **VIDEO-01-E2** (an unknown profile compares as a raw int, never as a shared `unknown`
string) and **VIDEO-02-E1** (the container-declared frame count is retained in evidence and is
demonstrably different from the counted value on at least one fixture). The remaining item this
plan touches, VIDEO-01-E1 (a 0/1 sample aspect ratio treated as 1:1 with `unset` in evidence), is
owned by plan 04-07, which registers `video.sar`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| attacker-controlled `codecpar` fields -> rendered strings entering the report | Profile, level and codec names are rendered from file-chosen integers into user-visible text and into snapshots. |
| attacker-controlled stream count and stream types -> per-stream scope derivation | The scope index ranks video streams among video streams; a file can declare many. |
| `PacketScanResult::partial` -> the decision to report a frame count | A count from a truncated sweep is a confidently wrong number. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-4-24 | Tampering | two different unknown profiles collapsing to one rendered string | high | mitigate | An unresolved profile renders its raw integer as the compared value, not a constant word, so two files with different unknown profiles compare as different. The raw integer is always in evidence regardless. |
