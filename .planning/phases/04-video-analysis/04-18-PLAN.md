<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a shipped check document -> an operator's reading of a `pass` | A doc that overstates what a verdict proves is acted on as if it were the rule; this is the "a muted gate is worth nothing" failure in reverse — a gate trusted for more than it says. |
| a test's own subject -> that test's skip predicate | A predicate read out of the output under test cannot detect that output disappearing; the test shrinks instead of failing. |
| a source comment -> the next author's mental model | A comment asserting an output does not exist invites a change that breaks the output nobody knew was there. |

| T-4-81 | Repudiation | a source comment denying an output the CLI prints | low | mitigate | The comment is corrected and an integration assertion over plain `list-checks` is added, so the claim now has a test behind it; the assertion was observed failing with the token removed from the format string. |
