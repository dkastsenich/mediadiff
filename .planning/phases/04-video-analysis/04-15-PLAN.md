<objective>
Make `video.interlace`'s `disagreement` evidence field mean something: `false` on a correctly
encoded interlaced file, `true` only when the container's declaration and the observed frames
genuinely conflict.

Purpose: 04-VERIFICATION.md's fourth gap and deferred-items.md's 04-10 entry. `interlace.cpp:206`
compares raw `AVFieldOrder` ordinals drawn from two disjoint subsets of the same six-value enum, so
`disagreement` is unconditionally `true` on every valid interlaced input — the "cries wolf gets
muted" failure at the evidence layer, recorded as intent by the source's own comment. Human
Decision 3: fix it now, correct the comment, and prove both directions with tests.
Output: a class-based cross-check, an honest comment carrying the read-back table, and tests that
go red without the fix.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| container `fiel` declaration -> the cross-check | A file-supplied declaration is one of the two inputs to a comparison a reviewer reads under `-v`. |
| per-access-unit parser output -> the cross-check | The other input is derived from attacker-controlled bitstream data by a third-party parser whose value domain this project does not control. |
| an evidence field -> a reviewer's attention | A field that is always true trains readers to ignore it, which silently disables the one case where it matters. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-4-66 | Repudiation | an always-true `disagreement` evidence field | medium | mitigate | The comparison moves to a field-order class, and real-fixture tests assert `false` on both non-conflicting interlace fixtures; the tests were observed failing under the old computation. |
| T-4-67 | Spoofing | a genuine container-vs-frames conflict reported as agreement | high | mitigate | The class mapping folds only pairs that name the same first-coded field; synthetic unit cases pin both conflicting directions (top observed against bottom declared, and its mirror) to `true`. |
| T-4-68 | Tampering | a field_order value outside the closed six-value enum | low | mitigate | The mapping is total and routes any unrecognised value to the unknown class rather than falling through to an unhandled branch, matching `field_order_name`'s existing default. |
| T-4-69 | Elevation of Privilege | an evidence-only field acquiring gating power | low | mitigate | The compare engine does not read `disagreement`; the plan's prohibitions forbid wiring it, and the real-fixture tests assert the compared value independently so a status change would fail there. |
| T-4-SC | Tampering | npm/pip/cargo installs | low | accept | No package manager is invoked and no dependency manifest changes. |
</threat_model>
