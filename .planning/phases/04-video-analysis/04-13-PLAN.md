<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a developer workstation's ffmpeg output -> the committed digest | The bytes a local encode produces are host-CPU-dependent; writing them into a file whose job is to record the designated leg's bytes silently substitutes one provenance for another. |
| `git show 8caf1f1:...` -> the restored lines | The restore trusts a historical blob to still describe today's recipes; if a recipe changed, the blob is a confident wrong answer. |
| a shallow CI checkout -> the no-rewrite guard | A guard whose reference object is unreachable can report success without having compared anything. |
