<flagged_assumptions>
**A1 — Timing on a developer workstation is not timing on a CI runner.** The number this plan
records is a single-machine measurement. It is evidence that the parser pass is cheap, not a
guarantee about any other machine — which is precisely why D-11 forbids turning it into a gate
here. Phase 5's `PERF-05` owns cross-run regression tracking on a designated leg.

**A2 — Overhead depends on codec.** Parsing `mpeg4` is cheaper than an H.264 NAL walk. The
measurement input is `mpeg4` because that is what the LGPL-only pinned generator can produce at
length, so the recorded number describes the cheaper branch. Record that caveat alongside the
number rather than presenting the ratio as codec-independent; Phase 5's reference file can carry a
richer codec mix if `PERF-03` needs one.

**A3 — Spec-less edge probe.** One of the 17 unresolved probe items is authored into this plan's
`truths`: **PROBE-03-E2** — a budget-exhausted or truncated scan must be visibly distinguishable
from a complete one, so a ratio is never computed silently from two incomparable runs.
</flagged_assumptions>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| an on-demand generator -> the developer's disk | A generator with no bound on duration or resolution can fill a disk from a mistyped argument. |
| a wall-clock measurement -> a merge decision | A number that becomes a gate on shared runners turns scheduling noise into a build failure. |
| the scratch directory -> the git working tree | An ungitignored scratch path turns a multi-minute media file into a commit candidate, violating the no-media-binaries-in-git constraint. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-4-11 | Denial of Service | the on-demand multi-minute generator | medium | mitigate | Duration, frame size, frame rate and an output byte bound are named constants; exceeding any bound fails with a message naming the constant rather than proceeding. Regeneration is skipped when a valid input already exists. |
| T-4-12 | Repudiation | an overhead number computed from a truncated sweep | medium | mitigate | The benchmark exits non-zero and prints no ratio when either leg reports `partial`, and prints both legs' `read_frame_call_count` and `accounted_bytes` so the reader can see the two runs were comparable. |
| T-4-13 | Tampering | a multi-minute media file entering git | medium | mitigate | `.mediadiff-bench/` is gitignored in the same commit that creates it, and an acceptance criterion asserts `git status --porcelain` is unchanged after a run. |
| T-4-14 | Denial of Service | CI cost if the benchmark were built or run on every leg | low | mitigate | The target is behind an `OFF`-by-default option, has no CTest registration, and an acceptance criterion greps the CI workflow to confirm nothing references it. |
| T-4-SC | Tampering | npm/pip/cargo installs | low | accept | No package is installed by this plan; the benchmark links only the existing `libmediadiff`. |
</threat_model>
