<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fork-originated pull request → CI workflow | Untrusted contributor code executes on the project's runners. The only boundary in this phase where code the maintainers have not reviewed runs with any project credential. |
| GitHub Packages NuGet feed → every build machine | A cache entry restored from the feed is compiled into or linked against the shipped binary, on CI and on every maintainer's machine. A poisoned entry propagates silently and persistently. |
| repository secret store → workflow environment | Where the cache-write credential becomes available to a running job. Its blast radius is the feed above. |
| pinned vcpkg registry → build tree | Third-party source enters the shipped binary, mediated by the `builtin-baseline` and `overrides` pins established in Plan 01. |

## STRIDE Threat Register

ASVS level 1; block on high severity. Built from `01-RESEARCH.md` § Security Domain, whose fourth named threat pattern for this phase is CI binary-cache poisoning. V10 supply-chain and V14 configuration are the applicable categories; there is still no auth, session or user-data surface.
