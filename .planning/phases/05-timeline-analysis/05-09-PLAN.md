## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| packet side data → priming resolver | `AV_PKT_DATA_SKIP_SAMPLES` is attacker-controllable container content |
| sample counts → time conversion | a crafted skip-samples value participates in a rational conversion at the stream's sample rate |
| priming state → comparison basis | a crafted "known" priming on one side could shift which basis a comparison uses |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-40 | Tampering | a crafted `skip_samples` value (e.g. `INT64_MAX`, or larger than the packet's own sample count) producing a fabricated first-audible-sample time and therefore a fabricated sync verdict | high | mitigate | the sample-to-time conversion goes through `core/rational.h`'s checked helpers and a failure yields `skipped:insufficient_data`; the resolved sample count is published in evidence so an implausible value is visible rather than silent |
| T-05-41 | Tampering | double-applying the edit list on top of libav's own, shifting every MP4 offset by exactly the priming amount and hiding or manufacturing a sync break | high | mitigate | `EditListEntry` is cited as evidence only; Test 5 asserts the composed value `-1024 + 1024 == 0` on a real MP4, and an acceptance criterion greps the analyzer for arithmetic use of `media_time` |
