<objective>
The `timeline.duration` triple and its internal-coherence note: container-declared, stream-declared and
computed durations, compared pairwise across files, with an internal disagreement raising a non-gating
`info` note even when both files share it.

Purpose: TIME-03's second half. The triple is the project's first check whose VALUE is one number but
whose meaning depends on three independently-absent sources — getting the absent handling wrong here is
how a tool reports "duration unchanged" on a file whose stream header lost its duration entirely.
Output: two registered checks with their `--explain` docs, the reconstructed-packet-duration rule from
doc 04 §1.3, a duration-delta fixture pair, and DOC-04 declared-set assertions for both.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| container-declared durations → the triple | `AVFormatContext->duration` / `AVStream->duration` are attacker-controllable header fields |
| packet durations → the computed member | a crafted packet duration participates directly in `pts + duration` arithmetic |
| fixture recipe → committed corpus digest | a recipe change alters bytes a byte-exact golden asserts |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-13 | Tampering | a crafted declared duration (e.g. `INT64_MAX`) overflowing the triple's rescale and producing a fabricated coherence verdict | high | mitigate | every rescale and subtraction goes through `core/rational.h`'s checked helpers; a failure yields `SkipReason::insufficient_data` with no value, never a wrapped number |
| T-05-14 | Tampering | a crafted packet duration making `pts + duration` overflow, corrupting the computed member | high | mitigate | `detail::checked_add` on the frame-end computation; the reconstruction helper degrades the whole measurement rather than emitting a partial sum |
| T-05-15 | Denial of Service | reconstruction of missing durations turning into an O(n²) walk on a 5,000,000-packet stream | medium | mitigate | reconstruction is a single pass over the already-sorted local index view, bounded by `kMaxPacketsPerStream`; no nested search is introduced |
| T-05-16 | Repudiation | a reconstructed duration presented as a declared one, so a user cannot tell a derived number from a container claim | medium | mitigate | the `duration_source` evidence field is set to `reconstructed` whenever any packet was reconstructed, and Test 3 asserts both states |
| T-05-17 | Tampering | a locally regenerated pre-existing digest line replacing a designated-leg hash | high | mitigate | `scripts/lint_corpus_digest_provenance.sh` runs in Task 3's `<verify>`; new names go to the provisional ledger only |
| T-05-SC | Tampering | dependency supply chain | low | accept | no npm/pip/cargo/vcpkg package is added by this plan (`05-RESEARCH.md` § Package Legitimacy Audit: not applicable to this phase) |
</threat_model>
