<objective>
Complete the T-2-33 control-byte choke point that plan 03-11 established but did not finish, closing
the three review findings 03-VERIFICATION.md records as out-of-gap but consequential.

CR-03 (Warning) — `src/report/junit.cpp`'s `xml_escape` substitutes only the four XML metacharacters
and passes every other byte through. Raw C0 control bytes are not legal XML 1.0 character data under
any escaping mechanism, and `meta.cpp`'s `sanitize_utf8` deliberately leaves them in place, deferring
to "the single render boundary". So a crafted tag value carrying `0x1B` or `0x00` is written verbatim
into the emitted `.xml`. `src/util/sanitize.h`'s own header comment asserts this file is fine because
`xml_escape` "handles its own context" — that assertion is false, and 03-VERIFICATION.md notes it
falsifies 03-11-SUMMARY.md's "88/88 threats closed" claim.

WR-01 (Warning) — 44 CLI diagnostics write `Error::message` straight to stderr, outside the three
files the lint scans. In `dir` mode those messages embed filenames from a directory listing, not from
argv, and this project deliberately enables VT processing on Windows.

IN-02 (Info) — the lint's scan list omits `src/cli/commands/inspect_render.h`, a fourth (correct)
call site, so a future regression there would be invisible to the gate; and the header comment names
a count that is already wrong.

**Fix, not defer** — the reasoning, stated because the gap-closure brief left it open: all three are
the same mechanism as the gap-1/gap-2 fixes (a control this codebase already built, incomplete at
one path), the fix is small and locally provable, and leaving CR-03 open leaves a Phase-3 SUMMARY
making a claim its own review disproved. A summary that overstates what shipped is exactly the kind
of quiet debt this phase's verification exists to surface.

Purpose: CONT-03 (`meta.tags` compared as a set, volatile keys shown under `-v`) and CONT-04
(`meta.tags.language`) are the checks whose values ARE the file-derived text at issue; their output
must be safe in every format the tool emits, not only in the terminal renderer.
Output: control-byte-safe XML, one sanitizing CLI diagnostic helper replacing 44 inline writes, a
lint whose scan list matches reality, and an `02-SECURITY.md` entry that is true.

Decision coverage: D-01 through D-06 were closed by plans 03-03, 03-09, 03-08, 03-10 and 03-02; this
plan re-implements none of them and changes no check's value.
</objective>
