structure — stride, PIDs, continuity, PCR, PSI — with no libav involvement and no payload
buffering.

keeps each within one agent's working context and lets the scanner be proven against TSDuck
goldens (plan 03-10) independently of check semantics.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| raw MPEG-TS bytes -> stride autodetection | The stride itself is inferred from file content; every subsequent offset depends on getting it right. |
| `adaptation_field_length` -> adaptation-field reads | A one-byte, fully attacker-controlled length gating a read inside a fixed-size packet. |
| `section_length` (12 bits) -> PSI section iteration | A declared length driving loops over program and elementary-stream entries. |
| 13-bit PID field -> per-PID state table | Attacker-chosen keys into a table, in a stream that can cycle all 8192 values. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-3-31 | Denial of Service | per-PID state table | high | mitigate | A fixed-size array over the structurally bounded 13-bit PID domain (8192 entries), heap-allocated so it cannot overflow a small thread stack. An `unordered_map` keyed on attacker input would grow to the same bound with hashing overhead and allocation churn for no benefit — the bound is in the wire format. |
| T-3-32 | Tampering | `adaptation_field_length` driving a read | high | mitigate | Validated against the packet's own remaining bytes BEFORE any adaptation-field read; every field inside (including the 6-byte PCR) is bounded by that validated length, not by the 188/192/204 packet size. A short length with `PCR_flag` set yields no PCR and increments the malformed counter. Behaviors 2 and 7 of Task 1/Task 2. |
| T-3-33 | Tampering | `section_length` driving PSI loops | high | mitigate | Validated against the bytes actually available before any program or ES loop iterates; a section claiming to span beyond the available payload is discarded and counted, never parsed from a truncated buffer. Behavior 9 of Task 2. |
| T-3-34 | Denial of Service | resync scanning on a file of pure noise | medium | mitigate | Resync scans forward only, never backward, and the overall walk is bounded by file length; a file with no valid stride ends with `complete = false` after one linear pass rather than retrying combinatorially. |
| T-3-35 | Tampering | PCR arithmetic (`base * 300 + extension`) | medium | mitigate | `detail::checked_mul` and `detail::checked_add`; a 33-bit base times 300 fits comfortably in int64 but the checked form makes the guarantee explicit rather than assumed, matching every other arithmetic site in the phase. |
| T-3-36 | Tampering | mux-rate estimate division | high | mitigate | `detail::checked_div` with an explicit skip for a zero or negative PCR delta — a division by a wrapped-to-zero delta would raise SIGFPE and terminate the process, which for a CI gate is a crash rather than a verdict. Behaviors 7 and 8 of Task 2. |
| T-3-37 | Repudiation | a stream that resyncs repeatedly still reporting numbers | medium | mitigate | `resync_bytes_skipped` and `malformed_packets` are recorded and surfaced, so plan 03-08's checks can degrade honestly rather than reporting per-PID counts from a stream that was half-garbage. |
| T-3-SC | Tampering | package installs | low | accept | No package installed; TSDuck is never linked or installed (D-04). FFmpeg 8.1 pin unchanged (03-RESEARCH.md Package Legitimacy Audit: not applicable this phase). |
