<objective>
**PHASE TRACER.** Wire one capability end-to-end through every layer this phase will touch:
a real media file on disk -> `DemuxSession` -> the pass-declaration seam -> a container
analyzer -> a `Measurement` -> the Phase-2 compare engine -> a rendered report.

The single path is `container.format`. It is doc 02 section 7 step 1's own choice
("DemuxSession + generic topology checks, immediately end-to-end visible through the phase-1
engine") and it touches every layer without needing `PacketScan`, any raw scanner, or any
new `SkipReason`. Everything else in this phase expands horizontally from this proven slice.

This is production code, not a prototype: the seam, the error contract, the log attribution
and the CLI wiring are the ones the whole phase keeps. Only the analyzer's breadth is thin —
one check instead of five — and widening it (plan 03-04) requires no architectural change.

Purpose: prove the probe architecture on the executor's best early-context tokens, so an
architectural dead end costs one commit rather than ten.
Output: `src/probe/{pass.h, demux_session, orchestrator}`, `src/analyzers/container/topology.cpp`,
`container.format` registered, all four CLI commands fingerprinting real media, and the first
synthesized fixtures.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| media file bytes -> `avformat_open_input`/`avformat_find_stream_info` | The first untrusted binary input this project parses. FFmpeg's own demuxers are the parser; mediadiff's exposure is what it does with the results and how long it lets the call run. |
| media file path -> Windows wide-API shim | A path is attacker-supplied in `dir` mode (any filename in the scanned tree). |
| libav log strings -> `Envelope.diagnostics` -> `--json` | libav formats file-derived text (codec names, container warnings) into log lines that this task starts capturing. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-3-05 | Denial of Service | `DemuxSession::open` | high | mitigate | A bounded wall-clock budget (`kDefaultProbeBudgetMs = 30000`, `--probe-timeout`) enforced via `AVIOInterruptCB`, mapping a timeout to `input_unsupported`/exit 65. Documented residual: the callback cannot preempt a blocked read syscall (`libavformat/file.c` never checks it) — accepted, since a wedged local read requires a hostile filesystem, not a hostile file. |
| T-3-06 | Denial of Service | `avformat_find_stream_info` on a crafted file with thousands of streams | medium | mitigate | The wall-clock budget bounds the call regardless of stream count; `stream_count()` consumers iterate `nb_streams` once with no per-stream allocation proportional to attacker input beyond libav's own. |
| T-3-07 | Tampering | libav log line -> `diagnostics` JSON | medium | mitigate | The callback retains a capped number of lines and counts past the cap (no unbounded growth from a file that logs on every packet); the strings are serialized through `serialize_document`'s JSON escaping. Terminal rendering of these strings is NOT yet safe — T-2-33 remains open and is closed in plan 03-11 before `tty_render.cpp` sees any file-derived text from this channel. |
| T-3-08 | Elevation of Privilege | `av_log_set_callback` global pointer | low | mitigate | Installed exactly once at process start from `main.cpp`; a lint-checkable single call site (`grep -c av_log_set_callback src/` equals 1) prevents a worker thread from silently replacing the process-global handler mid-run. |
| T-3-09 | Tampering | `scripts/gen_corpus.sh` recipe arguments | low | accept | Recipes are fixed literals in a developer-run script with no user input path; the script writes only into `$OUT_DIR`. Accepted: no injection surface exists because no value crosses a trust boundary into the command line. |
| T-3-SC | Tampering | vcpkg/npm/pip installs | low | accept | No package is installed. FFmpeg 8.1 is the Phase-1 pin, unchanged; 03-RESEARCH.md's Package Legitimacy Audit records "not applicable this phase". |
